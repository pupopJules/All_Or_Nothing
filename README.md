# JuTravel – Online Booker

LIVE SERVER: https://pupopjules.github.io/AllOrNothing/

## 1. Project Description

**JuTravel** is a simple tourism website designed to help users discover popular tourist destinations in the Philippines. It provides information about beautiful places such as Boracay, Baguio, and Palawan.

The website allows visitors to explore destinations and click on their names to visit external booking websites.

## 2. Website Features

- **Home Section** – Displays a welcome message for visitors.
- **Destinations Section** – Shows three popular tourist destinations in the Philippines.
- **Destination Images** – Displays pictures to make the website more attractive.
- **Clickable Destination Names** – Users can click a destination to visit an external booking website.
- **About Section** – Provides a short description of JuTravel.
- **Footer** – Displays the website name and copyright information.

## 3. Technologies Used

This website uses only basic HTML and CSS.

| Technology | Purpose |
|---|---|
| HTML5 | Creates the structure and content of the website. |
| CSS3 | Designs the appearance, colors, spacing, and layout. |

## 4. Website Structure

The website is divided into five main parts:

### Header
Contains the website name, JuTravel, and the navigation menu.

### Home
Contains the welcome message:
"Welcome to JuTravel Online Booker!"

### Destinations
Displays three destination cards:

- **Boracay** – Known for its beautiful white sand beaches.
- **Baguio** – Known for its cool weather and nature.
- **Palawan** – Known for its amazing natural landscapes.

Each destination has an image, name, short description, and external booking link.

### About
Explains the main purpose of the JuTravel website.

### Footer
Displays the copyright text and website name.

## 5. CSS Styling

The website uses CSS to make its design simple and organized.

Some CSS properties used include:

- `background` – Changes the background color.
- `color` – Changes the text color.
- `padding` – Adds space inside elements.
- `margin` – Adds space outside elements.
- `display: flex` – Arranges destination cards in a flexible layout.
- `justify-content: center` – Centers the destination cards.
- `flex-wrap: wrap` – Allows cards to move to another line when needed.
- `border-radius` – Makes the corners rounded.
- `object-fit: cover` – Makes images fit properly inside their containers.

## 6. Color Theme

JuTravel uses a green and light green color combination to create a fresh and relaxing tourism-inspired appearance.

- Dark Green: `#24785d`
- Light Green: `#d9eee3`
- Background: `#f5f8f6`
- White: `#ffffff`

## 7. How to Run the Website

1. Open Visual Studio Code or any text editor.
2. Create a folder named `JuTravel`.
3. Create a file named `index.html`.
4. Copy and paste the HTML and CSS code into the file.
5. Save the file.
6. Open `index.html` in your web browser.

## 8. Project Limitations

This is a beginner-level static website.

- It does not have a real booking system.
- It does not have a user registration or login system.
- It does not process payments.
- Booking links redirect users to external websites.
- It does not use a database or JavaScript.

## 9. Project Objective

The main objective of JuTravel is to demonstrate basic knowledge of HTML5 and CSS3 by developing a simple, informative, and user-friendly tourism website.
